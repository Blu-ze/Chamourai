Installation

  1. Installez Python sur votre ordinateur.
  2. Décompressez le fichier `chamourai-source.zip`.
  3. Dans le dossier du jeu, créez un environnement virtuel Python.
  4. Installez les dépendances avec `pip install -r requirements.txt`.
  5. Lancez `run.bat` sur Windows.
